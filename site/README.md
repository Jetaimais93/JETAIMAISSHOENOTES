# JE TAIMAIS · 鞋履选品笔记（纯展示网站）

> 📘 **日常使用请看《如何新增一篇笔记.md》**（在工作区根目录），里面是配好步骤的图文手册。本文件是技术与部署说明。

一个**只用来展示照片 + 微信联系**的极简网站。没有购物车、没有价格、没有库存。
纯静态、**零依赖、零构建**：整个文件夹丢到任何托管平台就能跑。

```
site/
├─ index.html            首页：首屏大图 → 一句话 → 封面墙 → 关于摘要 → 微信联系
├─ note.html?id=0        笔记页：封面大图 → 分段图文（可点任意图放大）→ 上下篇
├─ about.html            关于我 + 微信联系
├─ .pages.yml            可视化后台配置（Pages CMS）
├─ .nojekyll             让 GitHub Pages 不做额外处理
└─ assets/
   ├─ css/style.css      全部样式
   ├─ js/site.js         渲染封面墙、笔记分段、灯箱、复制微信号
   ├─ data/site.json     站点设置：网站名、口号、微信号、二维码、关于我
   ├─ data/shoes.json    全部笔记（标题 + 一句话 + 分段）
   └─ img/               所有图片
      ├─ hero.jpg          首页大图（16:9）
      ├─ about.jpg         关于页图片（4:5）
      ├─ wechat-qr.png     微信二维码
      ├─ campus/           第 1 篇笔记的照片（01–08 + cover）
      └─ shoes/            早期的占位图，**可以整目录删掉**
```

## 一、本地预览

**不要直接双击 index.html**（浏览器会拦截本地 JSON 读取，页面会空白）。
在这个文件夹里起一个本地服务器：

```bash
python3 -m http.server 8000     # 然后打开 http://localhost:8000
```

## 二、你平时只需要做这几件事

### ① 新增一篇笔记（详细步骤见《如何新增一篇笔记.md》）

后台「**选品笔记**」→ 新建 → **把图片拖进「图片」** → 填标题和开头一句话 → 保存。

- 第一张图自动作为封面（首页墙上的那张）
- 想写"分段笔记"（图 + 小标题 + 一句话）→ 在「图文分段」里加几段，每段拖入 1–2 张图
- 不写分段也行，那样笔记页会把剩余图片自动排成两列

### ② 删除图片

- **删掉整篇**：「选品笔记」里打开那条 → 删除条目
- **只删其中一张**：打开该条目 → 在图片列表里移除那一张 → 保存
- **清理素材库**：左侧「**图片库**」→ 选中图片 → 删除（能看到仓库里所有图片）

### ③ 改联系方式

「**站点设置**」→ 微信号 / 微信二维码图片。换了微信只要上传新二维码就行。

保存后 GitHub 会自动提交，网站约 1 分钟更新。

**微信号目前留空** —— 联系区只显示二维码（你选的方案）。以后想加微信号文字，在「站点设置 → 微信号」填上，页面会自动多出「微信号 + 复制微信号按钮」。

## 三、部署到 GitHub Pages（免费）

1. GitHub 新建仓库，例如 `taimais`，选 **Public**。
2. 把 `site/` 里**所有文件**（含 `.pages.yml`、`.nojekyll`）上传到仓库根目录，网页拖拽即可。
3. 仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → Branch `main` + `/ (root)` → 保存。
4. 等 1–2 分钟，网址是 `https://你的用户名.github.io/taimais/`。

> 建议**同一份代码再部署到 Cloudflare Pages**（连同一个仓库，免费、国内更快）。
> 两个地址都留着，哪个快用哪个；**再绑一个自己的域名**效果最好。

## 四、开启后台（Pages CMS）

1. 打开 <https://app.pagescms.org> → GitHub 登录 → 授权这个仓库
2. 读到 `.pages.yml` 后，左侧会出现：**选品笔记**、**站点设置**，以及素材管理的**图片库**
3. 想找人帮忙维护：在 Pages CMS 里**用邮箱邀请**，对方不需要 GitHub 账号

## 五、其他常用修改

| 想做的事 | 怎么做 |
|---|---|
| 换网站名 / 口号 | 后台「站点设置」→ 网站名、首页主标题、首页副标题（店铺文字会强制显示为大写） |
| 加/改微信号 | 后台「站点设置」→ 微信号（留空则只显示二维码） |
| 换微信二维码 | 后台「站点设置」→ 微信二维码图片 |
| 换首页大图 / 关于页图片 | 后台「站点设置」→ 首页大图、关于页图片 |
| 改「关于我」 | 后台「站点设置」→ 关于 · 正文（空一行分段） |
| 调整笔记顺序 | 前台顺序 = 后台列表顺序，把条目上下移动即可 |
| 上线前删掉顶部黑色提示条 | 删掉 3 个 HTML 里 `<div class="notice">…</div>` 那一段 |
| 删掉早期占位图 | 直接删除 `assets/img/shoes/` 整个文件夹 |
| 改字号 / 留白 / 主色 | `assets/css/style.css` 顶部 `:root` 的变量 |

## 六、图片规范

- 笔记内的图：**正方形或 4:5 都行**，长边 **1600px**、单张 **300KB 以内**
- 封面墙上的封面：建议**裁成 4:5 竖图**，墙面最整齐
- 首页大图：**16:9 横图**
- 同一批图用**同一个背景和光**（这次的绿 Campus 就做得很统一，保持这个拍法）
- 一篇 8–10 张最合适：整双、叠放、侧面、鞋头、鞋跟、大底、细节

## 七、说明

- 全站**只有展示与联系方式**，不含任何价格、库存、购买功能。
- 点任意图片可放大：电脑上用 ← → 翻页、Esc 关闭；手机上左右滑动。
- 内容都在 Git 里，改错了可以回滚；也可以随时搬到任何其他平台。
